## 🌿 Sobre esta Branch: `Exercicios`

Você está atualmente na branch **`Exercicios`**. Esta é a branch dedicada exclusivamente à resolução das atividades práticas, desafios e projetos menores propostos em aula.

---

## 🛠️ Tecnologias e Recursos Praticados (Django Ecosystem)

O foco deste repositório é aprender aplicação real do framework em cenários de mercado. Os exercícios o geral e cobrem:

* **Django Core:** Estruturação de projetos e aplicativos (`apps`), configuração de ambientes e gerenciamento de arquivos estáticos/mídia.
* **MVT Architecture:** Criação de `Models` complexos, construção de `Views` (Function-Based e Class-Based Views) e renderização dinâmica com o sistema de `Templates` do Django.
* **Django ORM:** Modelagem de banco de dados, relacionamentos (OneToOne, ForeignKey, ManyToMany), migrações (`makemigrations`/`migrate`) e queries avançadas.
* **Autenticação e Segurança:** Sistema nativo de login, logout, registro de usuários, controle de permissões e decorators de restrição de acesso (como `@login_required`).
* **Django Forms:** Validação de dados de entrada com `Forms` e `ModelForms`.
* **Django Admin:** Customização completa do painel administrativo para gerenciamento de dados.
