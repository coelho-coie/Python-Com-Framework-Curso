### 📋 Sobre o Projeto
Aplicação web desenvolvida nas aulas de Python do **SENAI Sertãozinho**. O objetivo é calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados, mostrando o resultado e a classificação de saúde.

---

### 🚀 O que vamos praticar
* Estrutura básica de um projeto em Django.
* Como usar formulários para enviar dados para o Python.
* Uso de condições (`if`, `elif`, `else`) para classificar o IMC.

### 🔧 Como rodar o projeto

1. Abra o terminal na pasta do projeto.
2. Crie o ambiente virtual:
   ```bash
   python -m venv .venv
    ```

Ative o ambiente virtual:
* Windows: `.venv\Scripts\activate`
* Linux/Mac: `source .venv/bin/activate`

Instale o Django:
```bash
pip install django

python manage.py runserver
```

Acesse no navegador: http://127.0.0.1:8000/
