
# Contador de Caracteres e Palavras (Django)

Uma aplicação web simples em Django que analisa textos enviados via formulário e exibe estatísticas em tempo real, como contagem de caracteres (com e sem espaços) e número total de palavras.

---

## 🚀 Funcionalidades

- **Total de Caracteres:** Contagem completa da string informada.
- **Caracteres sem Espaço:** Medição da extensão do texto ignorando espaços em branco.
- **Total de Palavras:** Contagem precisa de palavras (trata strings vazias ou compostas apenas por espaços).
- **Manutenção de Estado:** Retorna o texto digitado de volta para a tela após a submissão.

---

- **HTML5 / CSS3** (Templates Django)
